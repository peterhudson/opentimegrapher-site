# opentimegrapher.org

The website for [Open Timegrapher](https://github.com/peterhudson/timegrapher), an open-source timegrapher for mechanical watches.

The site is built with [Hugo](https://gohugo.io) and hosted on Cloudflare Pages. The user guide and the math chapters are not copied here. They are pulled from the app repo's `docs/` at build time, so each page exists in one place only.
