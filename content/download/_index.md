Open Timegrapher's desktop app and command line tool are on the [Releases page]({{< param releases >}}) for macOS, Windows and Linux.

## Before you open it

The builds are not signed, so macOS and Windows ask once for each new version before they open it. The [installing guide](https://github.com/peterhudson/timegrapher/blob/main/docs/reference/install.md) has the steps for each system.

## Build from source

You need Rust 1.90.0 or later. The [build instructions](https://github.com/peterhudson/timegrapher/blob/main/docs/developer/building.md) list the packages each platform needs.

## Then

Start with [Your First Take](/guide/02-your-first-take/).
